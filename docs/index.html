S3のオブジェクトを取得するLambda関数

bucket と key を受け取り、対象のS3オブジェクトの中身を返すだけの 小さなAWS Lambda関数です。このページでは仕様・ローカル環境構築・テストの流れをまとめています。

lambda_handler の仕様

条件ステータス内容
bucket または key が無い 400 "bucket/key is required" を返す
S3から正常に取得できた 200 オブジェクトの中身をUTF-8文字列として返す
S3アクセス時に例外が発生した 500 例外メッセージを返す

ローカル環境構築

# 1. リポジトリを取得
git clone https://github.com/ohtsuka-shota-se/study-python-tantai-siken.git
cd study-python-tantai-siken

# 2. 仮想環境を作成して有効化
python -m venv .venv
.venv\Scripts\Activate.ps1        # Windows
source .venv/bin/activate         # macOS / Linux

# 3. 依存パッケージをインストール
pip install -r requirements.txt

# 4. テストを実行
pytest tests/test_lambda_function.py -v

テストケースと検証対象の対応

  1. 1

    test_returns_400_when_bucket_or_key_missing 400

    bucketのみ欠落・keyのみ欠落・両方欠落の3パターンで400が返ることを確認。

  2. 2

    test_returns_200_with_object_content 200

    get_object の戻り値をモックし、本文が正しくデコードされ200で返ることを確認。呼び出し引数も検証。

  3. 3

    test_returns_500_when_connection_fails 500

    get_object.side_effect で接続エラーを再現し、500が返ることを確認。
